## 独立诊断模式

第 29 篇 `--terminate` 实测退出码 86，符合预期。

本机原生 Windows GDB 批处理命中 before_commit，取得全线程堆栈并继续到预期竞态输出；它不覆盖 Linux core 收集流程。

## 必须保留的验证边界

1. 第 17 篇可选 `--retry` 在旧记录中超时；本次只验证默认成功初始化路径，没有重跑异常重试。
2. 本次未执行 TSan、ASan、ARM 弱内存平台、磁盘故障注入或 Linux core 实验。
3. 第 08、44 篇通过表示预期的业务竞态反例复现；这些反例本身不是正确售票实现。
4. 正常 close 的成功不保证断电持久化；队列实验不替代日志器真实输出端故障测试。
5. 默认性能输出仅作运行记录，不证明通用加速比；不同分配器或真实 IO 的选择仍需目标负载测量。
6. 字体回退与 PingFang SC 字形不同；严格一致需在已合法安装该字体的环境重渲染。
