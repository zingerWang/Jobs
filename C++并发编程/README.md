46 篇独立文章，按照基础、同步、任务、内存模型、工程实战递进。文章文件名与篇号连续编号为 01—46，不使用 07.1、18.1 一类插入编号。原有 40 篇深化内容全部保留。

先读[实验环境与验证](实验环境与验证.md)，实测结果见[验证报告](验证报告.md)。共有 49 个验证目标：46 个文章示例、生命周期补测、深化协议测试与信号 handler 补例；Linux 专属目标在 Windows 明确跳过。默认不运行故意死锁或崩溃的模式。

[深化实验与验证](深化实验与验证.md)解释同步协议测试。第 41 篇与补充测试共用 SPSC 实现；第 45 篇的原始性能采样可通过 `tools/benchmark_notes.py` 收集。
