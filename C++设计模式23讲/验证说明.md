制作机：Windows + MSYS2 UCRT64；GCC g++ 16.1.0。

23 份 C++17 源文件已分别以 -Wall -Wextra -Wpedantic -Werror -O2 -g -pthread 严格编译，全部通过。随后分别运行，检查退出码、程序中的 assert 及标准输出，23/23 与预期一致。

验证结果.json 记录每一项的文件名、输出和源码 SHA-256；文章中的完整源码与交付 cpp 文件逐字对应。构建中使用 -save-temps=obj 规避本机临时目录中文路径兼容问题，这不影响模式含义。

本机没有执行 Linux、Clang 或 MSVC 测试，也没有将小例子当成性能基准或并发压力测试。单例示例使用原子计数，但本轮仅验证顺序场景；线程安全的其他边界在文中明确说明。

## 教学范围

每个程序展示一个模式的最小协作过程。工厂方法的 JSON 格式化只演示固定 hello 输入，不能当成通用 JSON 序列化器；模板方法中的 csv(data) 也是示意格式，不是完整 CSV 编码。

观察者示例为单线程同步通知，回调异常与递归通知需由真实业务约定。命令示例只撤销内存音量修改；状态、快照和代理均未实现数据库、远程调用或外部资源事务。

模式名称与分类按 GoF 经典 23 项组织，简单工厂和 RAII 等另作区分。编译运行只能验证已覆盖场景，不能代替真实组件的完整需求与测试。
