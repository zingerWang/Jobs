# 23 种设计模式的 C++ 实战

先打开 **23种设计模式的C++实战.html**，目录、代码和所有配图均可离线阅读。

- 正文按创建型 5 种、结构型 7 种、行为型 11 种讲解，覆盖全部 GoF 23 项。
- 每种模式有问题、类比、职责图、完整 C++17 程序、编译命令、输出和使用边界。
- examples/ 中每个 cpp 都有自己的 main，只能分别编译，不要一起链接。
- run_all.py 可以批量编译运行并核对输出，需要 Python 3.8+ 和支持 C++17 的 g++。
- assets/ 保留蓝灰色原生 SVG 与高清 PNG，未采用 Graphviz 风格。
- Markdown 编辑版需要与 assets/ 一起保留；HTML 已经内嵌全部图片。

建议初学先读策略、适配器、外观、观察者和工厂方法，再按目录补齐。代码中的 assert 用于检查示例结果；验证时不要定义 NDEBUG。

## 运行

Linux / macOS（已安装相应编译器）：

~~~bash
python3 run_all.py
~~~

Windows + MinGW g++：

~~~powershell
python run_all.py
~~~

必要时通过 --compiler 指定 g++ 路径。批量脚本面向 g++ 兼容选项，不适用于直接调用 MSVC cl；其他编译器和操作系统的运行情况不能由本机测试代替。

测试环境及局限见“验证说明.md”。示例是模式教学程序，不是完整支付、网络、图形或持久化组件。

## UML 与优缺点补充

每种模式保留职责示意图，并新增 UML 类图和独立的优点、缺点分析。共 48 张图（原有 25 张 + UML 23 张），提供 SVG 与 PNG。类图摘录关键成员，完整类型与签名以源码为准。
